# GophKeeper

Менеджер паролей GophKeeper - клиент-серверная система для безопасного хранения приватной информации.

## Возможности

- Регистрация, аутентификация и авторизация пользователей
- Хранение различных типов данных:
  - Пары логин/пароль (CREDENTIALS)
  - Произвольные текстовые данные (TEXT)
  - Произвольные бинарные данные (BINARY)
  - Данные банковских карт (CARD)
- Синхронизация данных между несколькими клиентами
- Шифрование данных на сервере (AES-256-GCM)
- JWT аутентификация с refresh tokens
- Локальное кэширование данных на клиенте
